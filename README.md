# adcopy

A Claude Code skill that writes direct-response ad copy for contractor and trade industries using a 4-part framework: avatar callout + pain, deeper pain points, solution, CTA (with the why first, then the CTA twice).

## Install

```
git clone https://github.com/Icarus-312/adcopy-skill ~/.claude/skills/adcopy
```

## Use

```
/adcopy roofing
```

Returns 3 paste-ready variants, each with a different hook angle and keyword.
